CHAPTER 03

数据源与接口

计划里所有可复用的抓取入口、必需的 Headers，以及已经验证会失败、不必再试的路径。

3.1 / Endpoints

主数据源与 Headers

就业信息主源为 scc.hnu.edu.cn 与公众号「湖南大学毕业生就业」。 下列接口均为计划内已验证可用的路径。

用途接口关键参数 / 说明
全量宣讲会 GET /module/getcareers type=inner、count=500、start_page / start / count。
字段：meet_day 日期、room 教室、view_count 浏览量、career_talk_id 详情 id。
实习网申 GET /module/getonlines recruit_type=实习招聘 必须传中文；传数字会返回空。count=200。
双选会列表 GET /api/jobfairs 含校外场，首页看不到；记下 fair_id。
最近 6 场快查 GET /api/career 与首页交叉校验。
首页 GET / 校验日期 + 时间 + 地点最准；冲突时以首页为准。
宣讲会简章全文 GET /detail/career?id={career_talk_id} 可读岗位表、薪资、面试间章节、网申链接。
校外双选会名单 GET hr.bysjy.com.cn/jobfair/get_jobfair_detail fair_id={id}&is_debug=1；取 data.companies[] 的 company_name / view_count，及 data.content 简章原文。
日历视图 GET /index/getcareerdays year_month / type / get_activity / panel_name / panel_id / is_yun_career。
通知公告 GET /module/getnotices?type_id=4124 4124 = 通知公告，1759 = 重点推介。

校内接口必需 Headers

getcareers 不带这两个头会返回 400：

X-Requested-With: XMLHttpRequest
Referer: https://scc.hnu.edu.cn/module/careers?type=inner

同源其它接口复用同一组头即可。

校外双选会必需 Headers

get_jobfair_detail 需要：

X-Requested-With: XMLHttpRequest
Referer: https://hr.bysjy.com.cn/campus/jobfair_detail_v1?fair_id={id}
User-Agent: (浏览器 UA)

带 is_debug=1 可拿到 companies[] 与简章原文。

3.3 / Corrections

历史纠错记录

口径类错误一旦写进结论就会反复误导，因此单独沉淀。

报名截止 ≠ 学生报名

双选会页面「报名截止」是企业报名截止；学生凭校园卡 / 学生证直接入场，无需报名。

主办方归属

11/14 智能制造类双选会主办方是湖南机电职业技术学院，不是长沙理工大学。

届别

用户是 2028 届，不是 2027 届。

企业「消失」判定

须跨源查完宣讲会排期 + 全部双选会 companies[] 才能判退出；广州高澜实为「岳阳高澜」转移到 11/24 机械类场。

列表消失 ≠ 活动取消

/api/jobfairs 是滚动窗口；判定下架必须查详情 current_status。31909 曾消失又回归。

占位公司名

「就业办2019」不是脏数据，须读详情 meet_name；真身是 N 城联动湖南大学专场。

3.4 / Fields

关键字段速查

结构化信号优先于标题与推断，这是筛选规则能落地的前提。

meet_day / room
宣讲会日期 / 教室；首页为准。
view_count
浏览量；浏览量 ÷ 招聘人数 = 竞争热度，浏览量 < 100 通常刚上线、竞争小好聊。
career_talk_id / fair_id
简章全文 / 双选会详情的主键。
companies[]
校外双选会参会企业；professionals / job_recruitment 多为空，须按 company_name 做关键词匹配。
about_major
岗位表需求专业；岗位表学历列先于人数看。
job_number / degree_require
招聘人数 / 学历要求；is_above_master_degree = 硕士岗。
salary / city_name
薪资 / 工作城市；薪资是否明写 = 企业诚意。
job_require
岗位任职要求原文，届别与专业清单常藏在这里，须下沉扫描。
used_interview_list
面试间；「面试间」章节 = 现场面试信号，优先级高于宣讲时间。
current_status
双选会是否未开始；列表消失时以此为准。
两个高频口径陷阱

「1 职位 N 百人」 = 统一网申入口，现场不收纸质简历； 「不限专业」不是跳过理由，也不是高匹配依据——军工研究所常这样写，但任职要求里明确偏好机械 / 控制 / 测控。
