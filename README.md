# 湖南大学 2028 届秋招求职作战计划

> 面向「控制科学与工程」硕士的秋招情报作业计划站点。
> 把宣讲会 / 双选会 / 实习网申三路数据，整理成「只跑值得跑的场次」的行动清单。

## 这份计划解决什么问题

2026 年秋的场次绝大多数面向 **2027 届**，而目标用户是 **2028 届**。
因此本季的核心不是拿 offer，而是：

1. **实习通道** —— 只投明确写了「2027 届及以后在校生」「实习岗」「校园大使」「毕业时间区间」的岗位；
2. **建立目标企业库** —— 采集「明年是否还来 / JD 关键词 / 硕士薪资口径」，滚动复用；
3. 正式秋招在 **2027 年秋**，本季全部动作都是为那一年做准备。

就业信息主源：湖南大学就业信息网 `scc.hnu.edu.cn` + 公众号「湖南大学毕业生就业」。

## 技术说明

- **纯静态站点**：无构建步骤、无外部 CDN、无第三方字体与脚本，离线亦可正常浏览。
- **响应式**：桌面多栏网格，移动端单栏 + 折叠导航；宽表格横向滚动。
- **可访问性**：语义化标签、SVG 图示带 `aria-label`、跳转锚点、键盘可操作的勾选框。
- **行动清单勾选**状态保存在本机 `localStorage`，不影响仓库内容。
- **部署方式**：GitHub Pages 源设为 `main` 分支根目录（`/`），仓库本身就是构建产物，无需 Actions 工作流；`.nojekyll` 用于关闭 Jekyll 处理，保证 `assets/` 下资源完整可用。
