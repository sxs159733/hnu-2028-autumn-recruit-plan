11/08 新增
  1. 届别原文第一过滤器：全库唯一写 2028 届的岗位在标题里，按公司名 + 专业筛会漏。
  2. 面试间详情页非空：列表 used_interview_list 全 null 是坑，详情 PAGE_DATA 里有跨天安排。
  3. 跨源查「消失」：企业从排期消失，须查完双选会 companies[] 才判退出。
  4. 实习专场信号：简章「为做好 XXXX 届实习工作」+「前置实地考察签校企合作协议」= 质量白名单。
11/09 新增
  1. 届别下沉到 job_require：万兴科技标题是 2027 届秋招，5 个岗任职要求写 2028 届；简章是第二个 2028 届岗位池。
  2. 列表消失 ≠ 取消：以详情 current_status 为准，31909 被挤出列表但活动与名单完好。
  3. 「不限专业」须读任职要求：结构化的 about_major / job_require 优先于列表专业栏。
  4. 只认企业数 delta：对口数 delta 的 ±1~7 波动来自词表口径，不是名单变动。
11/10 新增
  1. 毕业时间区间正则：补 (\d{4})年(\d{1,2})月及(之后|以后)毕业 等写法；只搜「2028 届」会漏掉海康威视这类硬对口岗。
  2. 占位 company_name 读 meet_name：「就业办2019」实为本校 N 城联动大型双选会，零通勤，性价比最高。
  3. 跨轮比较用对口企业名单：词表固化成显式清单，用名单而非百分比做纵向比较。
  4. 空名单分时间性 / 结构性：同系列连续 3 轮为空即判结构性不开放，停止刷接口，改公众号或现场盲扫。
事业编备选思维

审协 / 国电投 / 中核 / 军工研究所等事业编与研究所场次，专业常写「不限」但偏好机械 / 控制 / 测控， 值得作为 2027 秋招的备选方向提前采集薪资口径与编制信息。
