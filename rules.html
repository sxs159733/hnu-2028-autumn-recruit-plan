CHAPTER 04

筛选规则

从「最高优先级信号」到「跳过」，把每场活动归到四级匹配度； 并给出易误判案例与双选会专项筛选法。

4.1 / Priority

最高优先级信号

只要命中以下任一项，直接进入高匹配，不需要再靠行业推断。

专业原文

专业栏出现「控制科学与工程」「控制工程类」原文。 西北机电列表写「不限专业」，但任职要求首条就列了「控制科学与工程」，属硬命中。

岗位名关键词

运动控制 · 导航算法 · SLAM · 伺服 · 机器视觉 · 嵌入式 · 机电 · 飞控。 星邦智能的运动控制 / 导航算法 / 飞控岗全线命中。

学历与届别

硕士及以上结构化字段；或明确有 2028 届可投实习岗。 届别原文（含「毕业时间区间」）作为第一过滤器。

优先级关系

结构化 about_major / job_require 里的专业清单 优先于列表 professionals； 「面试间」现场面试信号 优先于宣讲时间；岗位表学历列 先于人数看。

4.2 / Grading

四级匹配度

每一场活动都要打一个标签，并写清理由。

高　直接列为必去

  • 专业原文含「控制科学与工程」
  • 岗位含运动控制 / 导航算法 / SLAM / 伺服 / 机器视觉 / 嵌入式 / 飞控
  • 明确有 2028 届可投实习岗

中高　值得跑，可顺路

  • 智能制造 / 电气 / 自动化 / 车辆 / 测控 / 热管理 / 半导体设备方向
  • 与硕士学历匹配

中　信息圈

  • 大厂制造业但岗位偏工艺、质量、生产
  • 专业栏空白，需到现场看海报

跳过　不必出门

金融保险 · 建筑地产 · 快消 · 教培 · 传媒 · 选调 · 纯化工材料 · 医药 · 餐饮。

4.4 / 2028 rule

2028 届特别处理

这一条覆盖上面所有匹配度：对口不等于可投。

可投

明确写了「2027 届及以后在校生」「实习岗」「校园大使」 或给出毕业时间区间下界（如「2026 年 9 月及之后毕业」）的，才可投。例：特斯拉 T-STAR、海康威视超新星。

只采集，不投简历

其余场次全部只采集三要素：明年是否还来 / JD 关键词 / 薪资口径。 现场目的是加 HR 微信，不是拿 offer。

4.5 / Job fairs

双选会专项筛选法

校外双选会不在首页展示，名单分批更新，需要单独一套判断口径。

简章里的两个高价值信号

  • 「为做好我校 XXXX 届毕业生实习工作」= 实习专场，与 2028 届时间轴直接对接。
  • 「凡涉及实习生招聘的单位，必须完成前置实地考察并签订校企合作协议」= 质量有保障，可作明年白名单。

筛选法

  • 企业数 × 对口率：30+ 家且 20% 对口 = 值得跑。
  • companies[] 的 professionals / job_recruitment 多为空，必须按 company_name 做行业匹配。
  • 判断放量只认企业数 delta，不用对口数 delta（词表口径会造成假波动）。
  • 列表消失 → 查详情 current_status，别删企业库条目。

行业关键词表（固化 v2 口径）

SOP 28 词 + 军工 / 测控 / 惯导 / 视觉类补充 22 词。词表必须固定，否则同一场 35 家能算出 82.86% 与 57.14% 两个结果。

机器人智能装备自动化机电 机械重工装备智能制造 数控精密传动液压 伺服电气电子新能源 汽车车辆轨道交通工程机械 模具轴承减速机传感器 电机驱动低空智能 测控惯导导航视觉 航空航天发动机仪器 光电通信微电子半导体 光子机床晶体中科 国科材料所齿轮链条 热工电源电池变压器
空名单分两类，别把预算刷在死接口上

连续 3 轮为空且属于同一系列（N 城联动 / 师范 / 传媒 / 昆山高校行）= 结构性不开放，该主办方不走 hr.bysjy.com.cn 报名通道，停止逐轮刷接口，改看主办方公众号或现场盲扫。 反之，临近活动 1–2 周企业数突然增长 = 时间性放量，值得复查。
